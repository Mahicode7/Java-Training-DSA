# Java Training and DSA

A repository containing **Java programming** and **Data Structures & Algorithms (DSA)** work completed as part of the **Java Training program** and **mini-project submission**.

---

## 📖 About the Repository

This repository was created as part of the **Java Training and Data Structures & Algorithms (DSA)** program during the **3rd Semester**.

The purpose of this repository is to maintain and demonstrate the **Java programming concepts, DSA concepts, programs, and mini-project work** completed during the training.

It also contains the **final mini-project** developed as part of the training.

---

## 🎯 Objectives

The main objectives of this repository are:

- To strengthen Java programming skills.
- To understand and implement Data Structures and Algorithms.
- To practice problem-solving using Java.
- To develop programming logic and algorithmic thinking.
- To apply Java concepts in a practical mini-project.
- To maintain project work using Git and GitHub.
- To demonstrate the learning and implementation completed during the training.
